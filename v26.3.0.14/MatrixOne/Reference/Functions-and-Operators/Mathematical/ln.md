# **LN()**

> LN(X) returns the natural logarithm of X.

## **Description**

LN(X) returns the natural logarithm of X. This function is synonymous with LOG(X).

## **Syntax**

```
> LN(X)
```

Reference to [LOG(X)](log.md).
