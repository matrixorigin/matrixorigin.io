# **DROP DATABASE**

> Drop a database.

## **Description**

Drop a database.

## **Syntax**

```
> DROP DATABASE [IF EXISTS] <database_name>
```

## **Examples**

```sql
CREATE DATABASE test01;

mysql> DROP DATABASE test01;
Query OK, 0 rows affected (0.01 sec)
```
