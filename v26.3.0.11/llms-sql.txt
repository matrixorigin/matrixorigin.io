- [SHOW SEQUENCES](https://docs.matrixorigin.cn/MatrixOne/Reference/SQL-Reference/Other/SHOW-Statements/show-sequences/) [mo-only]: SHOW SEQUENCES is used to view the name and list type of the current sequence list.
- [SHOW STAGES](https://docs.matrixorigin.cn/MatrixOne/Reference/SQL-Reference/Other/SHOW-Statements/show-stage/) [mo-only]: SHOW STAGES returns stage specific information.
- [SHOW SUBSCRIPTIONS](https://docs.matrixorigin.cn/MatrixOne/Reference/SQL-Reference/Other/SHOW-Statements/show-subscriptions/) [mo-only]: Returns all publication names, publishing tenant names, published database names, published table names, comments, time published to the tenant…
- [SHOW TABLES](https://docs.matrixorigin.cn/MatrixOne/Reference/SQL-Reference/Other/SHOW-Statements/show-tables/) [partial]: Shows the list of tables in the currently selected database.
- [SHOW VARIABLES](https://docs.matrixorigin.cn/MatrixOne/Reference/SQL-Reference/Other/SHOW-Statements/show-variables/) [partial]: SHOW VARIABLES shows the values of MatrixOne system variables.
- [USE](https://docs.matrixorigin.cn/MatrixOne/Reference/SQL-Reference/Other/use-database/) [full]: The USE statement tells MatrixOne to use the named database as the default (current) database for subsequent statements.
